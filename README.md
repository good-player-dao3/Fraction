# 分数工具库 Fraction Tool

一个简单的分数类库，支持加、减、乘、除、幂、开方、取余等操作。
A simple fraction library supporting addition, subtraction, multiplication, division, exponentiation, root extraction, and modulo operations.

---

## 特性 Features
- 支持分数的加、减、乘、除、幂、开方、取余
- 自动约分
- 支持与整数混合运算

## Features
- Fraction arithmetic: add, subtract, multiply, divide, power, root, modulo
- Auto reduction
- Mixed operations with integers
